# Assets & Visual References Directory (`assets/`)

Este diretório abriga todos os artefatos visuais, documentos de referência e recursos estáticos do produto:

* **Wireframes e Mockups de UI/UX** (PNG, SVG, PDFs de design).
* **Diagramas C4 e Esquemas de Arquitetura** exportados.
* **Documentos e PDFs de Requisitos de Negócio** originais.
* **Paleta de cores, logotipos e referências visuais de marca.**

### Como os Agentes devem utilizar esta pasta:
1. Sempre referencie imagens e diagramas no Markdown com caminhos relativos: `![Diagrama](assets/nome-do-arquivo.png)`.
2. Não armazene arquivos binários de código compilado aqui (apenas assets conceituais de design e documentação).
