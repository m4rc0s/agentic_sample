# Template de Aplicação

Este diretório serve como molde. Ao criar um novo serviço ou módulo físico de código:

1. Duplique este diretório para `apps/[nome-da-aplicacao]`
2. Atualize o arquivo `app_liquid.md` com as definições da aplicação.
3. Inicie a geração do código pelo agente conforme as tarefas de `features/*/epics/*/tasks.md`.
